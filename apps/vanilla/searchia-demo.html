Searchia Agent Studio POC

Embeddable AI Chat Widget (Vanilla JS)

This test page demonstrates the framework-independent Searchia AI Chat widget. It mounts directly to the DOM without an <iframe>, reuses the tested UI and markdown rendering from the reference repository, and runs against the decoupled MockSearchiaAdapter.

✓ Framework Agnostic ✓ No iframe ✓ Markdown & Code Copy ✓ Streaming Responses ✓ Isolated Adapter Layer ✓ Zero API Secrets Exposed
Status: Active with MockSearchiaAdapter. Click the floating "از سرچیا بپرسید" button in the bottom-right corner to open the chat panel. Persian is the default; switch to English in the panel header without losing the conversation.

How it is Embedded

Customers can embed Searchia chat on any static or dynamic website using standard HTML tags: 

<!-- 1. Include Searchia styles and script -->
<link rel="stylesheet" href="searchia-chat.min.css" />
<script src="searchia-chat.min.js"></script>

<!-- 2. Initialize widget on page load -->
<script>
  SearchiaChat.init({
    language: "fa", // default; also supports "en"
    triggerPosition: "fixed" // or "inline"
  });
</script>
